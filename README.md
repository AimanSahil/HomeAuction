# HomeAuction

A modern Flutter-based Home Auction application with Firebase integration.

## Features

- User Authentication
- Buyer & Seller Dashboard
- Property Listings
- Live Auction System
- Firebase Integration
- Modern UI Design

## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AimanSahil/HomeAuction.git
```

Run the project:

```bash
flutter pub get
flutter run
```
